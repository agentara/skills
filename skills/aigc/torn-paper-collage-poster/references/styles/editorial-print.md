# Editorial, Print, and Type Styles

Each style below is poster-suitable and supports readable typography. Use the prompt add-on as the style block after selecting the style in `../poster-styles.md`.

## torn-paper-editorial-collage

- Core keywords: torn paper, editorial collage, ripped layers, rough typography, stamps, tape, stickers, photocopy grain, evidence-board energy
- Prompt add-on: Build a premium torn-paper editorial collage poster with ripped paper layers as the main structure, a subject breaking through torn sheets, rough display type, readable labels, stamps, tape, stickers, halftone, photocopy grain, and tactile evidence-board energy.
- Best for: launches, cultural moments, founders, archives, newsy editorial posters.
- Avoid: clean certificates, one rectangular photo, paper used only as a border, fake evidence.

## magazine-feature-spread

- Core keywords: magazine cover, editorial portrait, feature headline, pull quote, refined crop, premium layout
- Prompt add-on: Create a premium magazine-cover poster with a decisive hero crop, one dominant feature headline, readable deck text, pull-quote rhythm, strong margins, and polished editorial photography or illustration.
- Best for: people, profiles, product stories, cultural essays.
- Avoid: tabloid clutter, fake magazine logos, unreadable body copy.

## newspaper-front-page

- Core keywords: broadsheet front page, bold masthead, columns, urgent headline, ink texture, newsprint
- Prompt add-on: Use a broadsheet front-page system: bold masthead-like title, strong headline hierarchy, column blocks, newsprint texture, photo or diagram window, and readable date/label fields only when supplied.
- Best for: announcements, current events, research moments, public statements.
- Avoid: fake newspapers with invented facts, tiny column filler, copied mastheads.

## punk-zine-sticker

- Best for: indie music, youth culture, streetwear, rebellious campaigns.
- Avoid: polished corporate layout, illegible chaos, fake brand stickers.

## risograph-ink-pop

- Core keywords: risograph, spot color, misregistration, grain, flat shapes, indie print

# Culture, Event, and Sports Styles

These styles are for public-facing events, entertainment, sport, and performance posters.

## festival-pop-event

- Core keywords: festival pop, saturated color blocks, playful big type, stage energy, event poster
- Prompt add-on: Create a festival pop event poster with large cheerful title, saturated color blocks, rhythmic shapes, stage or crowd fragments, and readable event information when supplied.
- Best for: festivals, pop-ups, exhibitions, music nights, launches.
- Avoid: fake sponsor rows, generic club flyer templates, muddy color overload.

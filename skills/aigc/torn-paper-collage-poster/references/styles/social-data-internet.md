# Social, Data, Internet, and Information Styles

These styles are for online culture, data storytelling, community, and attention-map posters.

## data-evidence-board

- Core keywords: data evidence board, annotated cards, pins, arrows, document fragments, readable findings
- Prompt add-on: Create a data evidence board poster with a main thesis title, annotated cards, arrows, pins, document fragments, and readable findings while avoiding invented facts.
- Best for: research, market theses, case studies, investigations.
- Avoid: fake maps, fake quotes, tiny unreadable notes, dashboard slide design.

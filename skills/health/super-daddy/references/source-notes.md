## Attribution Style

When answering, do not cite local file paths. If attribution is helpful, cite short source titles:

- "这和《2020婴幼儿健康辅食白皮书》中强调的辅食原则一致..."
- "崔玉涛在生长发育评估相关公开分享中强调，要看曲线和趋势..."
- "育学园医疗服务白皮书里也提到，家长就诊前记录问题和病情很重要..."

Keep the answer practical. Source notes support confidence; they should not turn a parenting answer into a bibliography unless the user asks.
